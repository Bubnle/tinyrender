
# Bresenham’s line algorithm 布雷森汉算法
## simple method 简单方法
    使用参数方程 t belong to 0-1 
    xt = (1-t)ax + t(bx)
    yt = (i-t)ay + t(by)
## different sampling strategy 不同采用方法
    简单方法当中，是按照t参数来求得x与y；
    但是这种方法因为t是均匀！
    对于长线段来说，可能存在中间不连续的情况；
    就是t取任何值都不会覆盖某一点x' y'
    t = (x - ax) / (bx - ax)
    因此就反过来 用t表示x，再代入y当中表示出y；这样就可以消除t参数了
    此时就是按照步长；来一列一列的画了；

### new problems 新的问题
#### 线段消失
    当我们这样改正之后会发现其中的线消失了
    因为我们从x = ax开始采样，但是ax 本身大于bx 所以并未画出结果
    只需要swap即可
#### 采样点少
    斜率很大的情况下，x步长即使很小，y的变化很大，我们需要画很多点
    但是我们反过来y步长很大x的变化却很小；
    所以当斜率过大就更改为对y进行步长增长操作即可


### optimization 优化
#### 浮点数乘法优化为加法
增量计算，避免每次重复求值

#### 增加error
避免每次调用round进行四舍五入

#### 将error优化成int
扩大误差成为int类型
将原始的
``` error += std::abs(by-ay)/static_cast<float>(bx-ax); ```
扩大误差，两侧同时乘以(bx - ax) * 2 ;
``` ierror += 2 * std::abs(by-ay);  ```
同样需要改变的是当误差扩大，每次减去的也是 (bx - ax) * 2；

## 浮点版本的判断

```cpp
error += dy / dx;      // 每步累加斜率
if (error > 0.5) {     // 偏离超过半个像素，y 就该进 1
    y += 方向;
    error -= 1;        // 进了 1，所以误差扣掉 1
}
```

这里有两个麻烦：`dy/dx` 是除法（会出小数），`0.5` 也是小数。

## 关键一步：两边同乘 2·dx

把所有量（累加量、阈值、扣除量）都乘以 `2*dx`，不等式方向不变，但小数全部消失：

| 原来（浮点） | 乘以 2·dx 后（整数） |
|---|---|
| 每步累加 `dy/dx` | `dy/dx × 2dx = 2·dy` |
| 阈值 `0.5` | `0.5 × 2dx = dx` |
| 扣除 `1` | `1 × 2dx = 2dx` |

所以每步累加的就是 `2 * dy`，也就是 `2 * |by-ay|`。


```最终得到的line就是完整的Bresenham算法```

# 背面剔除

## 1. 带符号面积

```cpp
double signed_triangle_area(ax, ay, bx, by, cx, cy)
  = 0.5 * ((by-ay)*(bx+ax) + (cy-by)*(cx+bx) + (ay-cy)*(ax+cx))
```

化简后：

$$S=\tfrac12\,(\vec{AB}\times\vec{AC})=\tfrac12\big[(b_x-a_x)(c_y-a_y)-(b_y-a_y)(c_x-a_x)\big]$$

- |S| 是三角形面积，**符号表示 A→B→C 的绕向**。
- y 轴向上的坐标系里：**逆时针为正，顺时针为负**。
- 验证：A(0,0)、B(4,0)、C(0,3) 得 +6，交换 B、C 得 −6。

## 2. 两个可以证明的结论

1. **交换任意两个顶点，面积变号**（叉积是行列式，交换两列变号）。
2. **同一个面从另一侧看，绕向反过来**（纸翻面，或钟表从墙后看）。

## 3. 背面剔除的逻辑

1. **约定**：模型里每个三角形，从**外面**看是某个固定绕向（例如逆时针）。这是人规定的，不需要证明。
2. 朝向相机的面：相机在外侧，看到约定的绕向。
3. 背对相机的面：相机在里侧，看到相反的绕向。
4. 所以投影到屏幕后算 S 的符号，符号对就是正面，符号反就是背面，丢弃。

不用真的去"看"，算一个数的正负就够了。等价的另一种做法是用法线和视线的点积 n·d 的符号判断。

## 4. 一维类比（教程里的图）

- 线段用 B_x − A_x 的正负表示"向右 / 向左"。
- 因为多边形**封闭、绕向固定**，向右的边只可能在靠相机的一侧，向左的边只可能在背离相机的一侧。
- 所以符号间接给出了前后关系。三角形只是升了一维：线段的"左右"变成三角形的"顺逆时针"。
- 图里的 y 相当于 3D 里的深度 z，屏幕只剩 x。
